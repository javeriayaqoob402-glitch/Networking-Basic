# Linux System Information Commands

## df -h

Displays disk storage usage.

``` bash
df -h
```

## du -sh

Displays file/folder size.

``` bash
du -sh Documents
```

## uptime

Shows system running time.

``` bash
uptime
```

## uname -a

Shows OS, hostname, kernel version, architecture.

``` bash
uname -a
```

## lscpu

Shows CPU information.

``` bash
lscpu
```

## lsblk

Shows storage devices and partitions.

``` bash
lsblk
```

## Logs

Logs are records of important system activities.

## journalctl

View system logs.

``` bash
journalctl
```

## journalctl -f

View live system logs.

``` bash
journalctl -f
```

## journalctl -u ssh

View SSH service logs.

``` bash
journalctl -u ssh
```
